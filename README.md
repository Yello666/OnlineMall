# OnlineMall 电商平台（Spring Cloud 微服务）

> 一个基于 **Spring Cloud 微服务架构** 的分布式电商系统，完整覆盖电商核心业务链路，适合用于学习微服务架构设计、分布式事务与高并发场景下的服务治理。

---

## 项目概述

**OnlineMall** 是一个基于 Spring Cloud 生态构建的电商平台后端项目，采用微服务架构进行系统拆分，围绕真实电商业务场景设计并实现了从用户访问到下单支付的完整业务流程。

项目通过统一网关进行流量入口管理与权限校验，引入服务注册发现、配置中心、服务间通信、限流熔断、分布式事务与消息队列等组件，具备良好的 **可扩展性、高可用性与工程实践价值**。

* 项目时间：2025 年 12 月
* 开发方式：独立开发

##  系统架构

```text
                ┌────────────┐
                │   Client   │
                └─────┬──────┘
                      │
              ┌───────▼────────┐
              │ Gateway (鉴权) │
              └───────┬────────┘
      ┌───────────────┼────────────────┐
      ▼               ▼                ▼
 User Service   Product Service   Cart Service
      │               │                │
      ▼               ▼                ▼
 Order Service ──► Inventory Service ◄── Payment Service
      │
      ▼
   RabbitMQ / Seata
```



##  服务拆分说明

| 服务名             | 说明             |
| --------------- | -------------- |
| user-service    | 用户注册、登录、身份校验   |
| product-service | 商品信息管理与查询      |
| inventory-service   | 商品库存管理与扣减      |
| cart-service    | 购物车管理          |
| order-service   | 订单创建与状态管理      |
| payment-service   | 支付与交易流程        |
| gateway         | 统一网关、路由转发、权限校验 |



## ✨ 项目亮点

### 1.微服务架构与统一网关设计

* 基于 **Spring Cloud** 构建微服务体系，按业务域进行合理拆分
* 使用 **Nacos** 实现服务注册与发现、统一配置管理，支持配置热更新
* 通过 **Spring Cloud Gateway** 作为系统唯一入口，集中处理：

  * 路由转发
  * 登录校验
  * 权限控制

有效提升系统安全性与可维护性



### 2.业务解耦与流量削峰

* 使用 **RabbitMQ** 对下单后的非核心流程进行异步处理：

  * 清空购物车
  * 延迟关闭未支付订单

有效降低下单接口同步链路复杂度，实现业务解耦与流量削峰



### 3.分布式事务一致性保障

* 在下单流程中引入 **Seata AT 模式**：

  * 统一管理订单创建与库存扣减事务
  * 自动记录回滚日志（Undo Log）
  * 库存扣减失败时自动回滚订单数据

确保异常场景下数据强一致性



### 4.服务保护与熔断降级设计

* 使用 **Sentinel** 实现下单链路的限流与熔断保护
* 针对库存等核心下游服务配置：

  * 超时规则
  * 异常比例熔断规则
* 结合 **OpenFeign 降级机制**，在依赖异常时返回友好降级响应

防止请求堆积，保障系统高可用
